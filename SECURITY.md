# Security policy

## Supported versions

Security fixes are released for the latest minor version of `pine/commerce` (currently 1.3.x). Please keep client
projects on the latest release – Admin › Updates shows when one is available.

## Reporting a vulnerability

Please **do not open a public issue** for security problems. Report them privately through GitHub's
**"Report a vulnerability"** button on the [Security tab](https://github.com/SetWebUK/ecom-core/security) of this
repository (private vulnerability reporting).

Include the affected version, steps to reproduce, and the impact you expect. We aim to acknowledge reports within
5 working days and to release a fix, with credit if you want it, as soon as one is ready.
